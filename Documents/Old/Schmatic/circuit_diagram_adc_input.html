模拟信号采集前端 (ADC Input Chain) 直通/衰减/偏置与防护原理图

模拟采集调理链路 (ADC Input Chain) 核心设计解析：
  • 输入隔离与保护 (Cin / R1)： Cin (10μF) 彻底阻断被测电路的直流偏移；R1 (10kΩ) 为直通档提供限流，防止输入端意外过压打穿 4053 开关通道。
  • 双量程动态切换 (74HC4053 X通道)：
    • 直通档 (1× / X0)： 针对毫伏级小信号高灵敏捕捉，无分压衰减。
    • 衰减档 (0.1× / X1)： 由 R2 (90kΩ) 与 R3 (10kΩ) 构成 10:1 精密分压，将输入电压上限扩展 10 倍。
  • 共模工作点注入 (R_bias_in = 100kΩ)： 位于 COM_X 输出节点，将经过隔直选通后的双向交流信号直流基准精确锁定在 VBias = 1.65V，确保信号全动态对称分布于 ADC 最佳线性工作区 (0 ~ 3.3V)。
  • 双向过压钳位与高频滤波 (D1/D2 + C_filter)：
    • 肖特基二极管 D1/D2 (BAT54S) 将采样点瞬态电位强制钳位在 -0.3V ~ +3.6V 之间，杜绝过冲高压击穿 MCU 的 ADC 引脚。
    • C_filter (100pF) 与前端内阻构成低通抗混叠滤波，滤除射频杂波与开关毛刺。
