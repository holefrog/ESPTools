## 1. 项目定位

手持式混合信号分析与寻迹测试终端，一台设备同时做三件事：

1. **示波器**——ADC 采集输入信号，2.4" TFT 实时显示波形；
2. **信号发生器**——PCM5102A 经探针输出测试信号（1×/0.1× 两档）；
3. **声学寻迹**——MAX98357A 驱动喇叭，用耳朵确认信号特征（监听探针输出 / 寻迹 ADC 输入，双模式软件切换）。

设计哲学：Fail Fast、YAGNI，成品模块 + 分立模拟，不做过度设计。

## 2. 系统架构

```
                         18650 + Type-C 5V 2A 升压充放电一体模块
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    ▼                                               ▼
              5V 总线                                    3V3 总线（S3 板载 LDO）
   MCU / PCM5102A / MAX98357A              74HC4053 / 显示 / Vbias / D1钳位
                    │                                               │
 ┌──────────────────┴──────────────────┐              ┌─────────────┴──────────────┐
 │ I2S0主机 BCLK=GP6/LRCK=GP4          │              │ 模拟输入链路               │
 │  ├─ DIN=GP5  → PCM5102A → LROUT     │              │ ADC_In1→R2→C2→A           │
 │  │             2.1Vrms              │              │   A→R8→X0(1×) →┐           │
 │  │              ↓ C3               │              │   T→X1(0.1×) →┤4053→X→GP1  │
 │  │             N_C3 → 4053-Y       │              │   D1/D2钳位@X  C4旁路      │
 │  │              ├─ Y0: 0.1× ─┐     │              │   Vbias=1.65V              │
 │  │              └─ Y1: 1× ──┴→ C1 → DAC_Out1    │              └────────────────────────────┘
 │  └─ I2S1从机（共用BCLK/LRCK）       │
 │      DIN=GP11 → MAX98357A → 喇叭    │
 └─────────────────────────────────────┘
              ▲ SPI(GP8/9/10) + EC11(GP7/12/13)
              ▼
     ST7789 2.4" 显示 + 旋转编码器
```

**关键架构决策**（2026-10-02 三方确认）：选 ESP32-S3 SuperMini 而非经典版，因为经典版 ADC DMA 需占用 I2S0 的 ADC 模式，会吃掉一路 I2S，MAX98357A 将无家可归。S3 的 ADC DMA 不占 I2S，双 I2S 才成立。

## 3. GPIO 分配（以 ESPTools-2/6 为准）

| 引脚 | 功能 | 连接 |
|---|---|---|
| GP1 | ADC 输入 | U1.X（C4=100pF 旁路） |
| GP2 | U1.B | Y 输出档位：0=Y0(0.1×)，1=Y1(1×) |
| GP3 | U1.A | X 输入档位：0=X0(1×)，1=X1(0.1×) |
| GP4 | I2S LRCK | U2.LCK + U3.LRC |
| GP5 | I2S DOUT | U2.DIN（PCM5102A） |
| GP6 | I2S BCLK | U2.BCK + U3.BCLK |
| GP7 | 编码器 PUSH | DISP1.PUSH |
| GP8 | 显示 DC | DISP1.DC |
| GP9 | 显示 SDA/MOSI | DISP1.SDA |
| GP10 | 显示 SCL | DISP1.SCL |
| GP11 | I2S DOUT | U3.DIN（MAX98357A） |
| GP12 | 编码器 A | DISP1.A |
| GP13 | 编码器 B | DISP1.B |
| TX/IO43、RX/IO44 | — | 悬空 |

电源：5V=MCU.5V、U2.VIN、U3.Vin、U3.SD；3V3=MCU.3V3、U1.VDD（C7=100nF 去耦）、D1.K、R11 上端、DISP1.VCC/RES/BLK；GND 见第 6 节。

## 4. 模拟输入链路

```
ADC_In1(Pin2信号/Pin1接地)
  → R2(4.7k) → C2(1uF) → 节点A
      A → R4(91k) → T → R3(10k) → Vbias(1.65V)
      A → R8(10k) → U1.X0          …1× 档
      T → U1.X1                    …0.1× 档
      U1.X → GP1，C4(100pF)→GND，D1/D2 钳位在 X 节点
Vbias: R11/R12=10k/10k + C5(10uF) + C6(100nF) = 1.65V
U1: VDD→3V3，VSS/VEE/Inh/C/Z→GND
```

| 参数 | 1× 档（X0） | 0.1× 档（X1） |
|---|---|---|
| 增益 @1kHz | 0.9554 | 0.0946 |
| 直流工作点 | 1.65V | 1.65V |
| 输入阻抗 | 105.6kΩ | 105.6kΩ |
| 满量程（输出 0.45~2.85V） | ±1.26Vpk | ±12.7Vpk |
| 20kHz 衰减 | — | -0.057dB |

设计要点：
- **钳位结构**（2026-10-04 定稿）：D1/D2 在 X/ADC 节点（D1.A→X、D1.K→3V3；D2.K→X、D2.A→GND），X0 串 R8=10k 限流，节点 A 无钳位。旧方案（钳在 A）会导致 0.1× 档超过 ±2V 即削顶，量程扩展失效。
- **过载行为**（仿真验证）：0.1× 档 12.7Vpk 无削顶；误操作（1× 档入 12Vpk）时 X0 被钳在 -0.31~3.60V，R8 限流 0.84mA，4053 安全。
- **二极管选型**：肖特基优先（BAT54/1N5819，钳在 3.6V/-0.3V）；手头只有 1N4148 也可用（钳在 4.0V/-0.7V，电流 <1mA 由 S3 内部 ESD 分担，不损坏但钳位较"软"）。
- **直流失配**：D1/D2 漏电流失配最坏引入约 150mV 偏移，由固件开机零点校准吸收（输入悬空/短接采约 100 点取平均存 NVS，显示时扣除）。
- **4053 Ron**：3.3V 下约 150~250Ω 且随信号漂移，是本机最大的模拟误差源（约 1~2%），校准后可接受。

## 5. 音频/输出链路

```
PCM5102A LROUT（2.1Vrms，地电位中心）→ C3(10uF) → N_C3（R10=10k→Vbias 定 1.65V）
  N_C3 → R7(100k) → U1.Y0 → R6(1k) → R5(10k) → Vbias   …0.0991（-20.08dB）
  N_C3 → R9(1k)  → U1.Y1                               …直通 1×
  U1.Y → C1(10uF) → DAC_Out1（Pin2信号/Pin1接地），R1=100k 下拉
```

- GP2=0 选 Y0（0.1×，灵敏电路/精细查找），GP2=1 选 Y1（1× 全幅约 2Vrms，信号注入/级间寻迹）。
- BIST 自检期望值：Y0 输出 0.21Vrms（2.1×0.0991=0.208，仿真确认）。
- Y0/Y1 直流均为 1.65V，档位切换无跳变；C1 右端由 R1 定 0V。
- PCM5102A 负载：N_C3 等效约 5kΩ，规格最小 1kΩ，裕量充足；C3=10uF 在 20Hz 仅 -0.1dB。
- MAX98357A：Vin/SD→5V（常使能，不占 GPIO），GAIN→GND（12dB 档），SPK±悬空（喇叭未接时）。
- 双 I2S：I2S0 主机产生时钟，I2S1 从机共用 BCLK/LRCK、独立 DIN；I2S0 时钟常开，静音=DMA 喂零；**I2S1 从机 TX 稳定性待实测**（固件风险项）。

## 6. 显示/交互/电源

- **显示**：ST7789 2.4"，VCC/RES/BLK→3V3，CS→GND，K0 悬空；EC11：A→GP12、B→GP13、PUSH→GP7。
- **电源**：单节 18650（直接焊接）+ Type-C 5V 2A 升压充放电一体模块（型号引脚待实物核实）。
- **去耦**：C7=100nF（U1.VDD→GND，**PCB 布局时必须紧挨 U1 的 16 脚**）；Vbias PSRR@1kHz=-76dB。

## 7. 固件需求

| 模块 | 要求 |
|---|---|
| Core 0 | ADC DMA 采集（GP1）+ I2S0 信号发生 + I2S1 喇叭输出 |
| Core 1 | ST7789 波形 UI + EC11 菜单交互 |
| ADC | DMA 模式；开机零点校准（100 点平均存 NVS）；注意 S3 ADC 非线性，定量测量需逐档校准 |
| I2S0 | 主机，BCLK=GP6、LRCK=GP4、DOUT=GP5 → PCM5102A |
| I2S1 | 从机，共用 BCLK/LRCK，DOUT=GP11 → MAX98357A；切采样率先停 I2S1 |
| 喇叭模式 | 监听模式（播探针信号）/ 寻迹模式（播 ADC 输入），EC11/菜单切换 |
| BIST | 开机自检：Y0 档期望 0.21Vrms；菜单支持环路自检 |

## 8. 已知风险与待确认项

1. PCM5102A 模块的 A3V3/XSMT 引脚定义按实物模块核对（A3V3 多为板载 LDO 输出，不可倒灌）。
2. 各模块 1 脚方向对实物核对。
3. I2S1 从机 TX 在 ESP32-S3 上的稳定性实测。
4. Deep sleep 时若输入端恰有 20V 过载，钳位电流（约 3.5mA）灌入 3V3、无负载吸收，轨会被抬高（概率极低）。
5. 洞洞板布局已定 9×12cm 分区方案（2026-10-04）；画 PCB 时 C7 紧挨 U1.VDD，I2S 时钟走线避开模拟区。
