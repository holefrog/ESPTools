## 1. 项目定位

手持式混合信号分析与寻迹测试终端，一台设备同时做三件事：

1. **示波器**——ADC 采集输入信号，2.4" TFT 实时显示波形，继电器自动量程（1×/0.1×）；
2. **信号发生器**——PCM5102A 经探针输出测试信号，软件调幅；
3. **声学寻迹**——MAX98357A 驱动喇叭，**只播 ADC 输入的音频**；想听发生器输出时，拿输入探针碰一下输出端子（BIST 闭环）。

设计哲学：Fail Fast、YAGNI，成品模块 + 分立模拟，不做过度设计。

## 2. 系统架构

```
                         18650 + Type-C 5V 2A 升压充放电一体模块
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    ▼                                               ▼
              5V 总线                                    3V3 总线（S3 板载 LDO）
   MCU / PCM5102A / MAX98357A / 继电器线圈   显示 / Vbias / D1钳位 / 继电器触点
                    │                                               │
 ┌──────────────────┴──────────────────┐              ┌─────────────┴──────────────┐
 │ I2S0主机（唯一） BCLK=GP6/LRCK=GP4  │              │ 模拟输入链路（继电器自动量程） │
 │  DOUT=GP5 ──┬─→ PCM5102A DIN       │              │ ADC_In1→Rp→C1→节点A        │
 │             └──→ MAX98357A DIN     │              │   A→R3(91k)→T→R4(10k)→Vbias│
 │  L声道=ADC音频 → 喇叭（只取左声道） │              │   A→R8(10k)→继电器COM      │
 │  R声道=发生器波形 → PCM5102A ROUT  │              │     ├─NO→ADC …1×档         │
 │              ↓                    │              │     └─NC→T   …0.1×档       │
 │  ROUT(U2.13)→C3→1k→C1→DAC_Out1    │              │   D1/D2钳位@ADC  C4旁路    │
 │  （软件调幅，不走4053）             │              │   Vbias=1.65V              │
 └─────────────────────────────────────┘              └────────────────────────────┘
              ▲ SPI(GP8/9/10) + EC11(GP7/12/13)
              ▼
     ST7789 2.4" 显示 + 旋转编码器
```

**关键架构决策**：
- 2026-10-02：选 ESP32-S3 SuperMini（经典版 ADC DMA 占 I2S，MAX98357A 无家可归）。
- 2026-10-08：单 I2S（删 I2S1，从机稳定性风险消失）；喇叭只播 ADC；输出不走 4053；**4053 整颗删除**。

## 4. 模拟输入链路（分支 D：继电器自动量程）

```
ADC_In1(Pin2信号/Pin1接地)
  → Rp(4.7k) → C1(1uF) → 节点A
      A → R3(91k) → T → R4(10k) → Vbias(1.65V)
      A → R8(10k) → 继电器COM
                      ├─ NO（线圈吸合）→ ADC …1× 档
                      └─ NC（线圈断电）→ T   …0.1× 档
      ADC节点：C4(100pF)→GND，D1/D2 钳位
Vbias: R11/R12=10k/10k + C5(10uF) + C6(100nF) = 1.65V
继电器：小信号继电器（G6K/TXS2/HE721A），SPDT，线圈3.3V/5V；
        NPN(2N3904/SS8050)驱动，1N4148续流二极管；推荐非锁存
```

| 参数 | 1× 档（NO） | 0.1× 档（NC） |
|---|---|---|
| 增益 @1kHz | 0.9554 | 0.0946 |
| 直流工作点 | 1.65V | 1.65V |
| 输入阻抗 | 105.6kΩ | 105.6kΩ |
| 满量程 | ±1.26Vpk | ±12.7Vpk |

**自动量程逻辑（固件）**：
1. 上电默认 0.1×（NC，线圈断电），测幅度
2. 幅度 < 满量程 10% → GPIO 高 → 切 1×
3. 1× 下 ADC 削顶 → GPIO 低 → 切回 0.1×
4. 加回差防抖动；切换时间约 1ms

**设计要点**：
- **为什么不用 4053**：4053 引脚 ESD 二极管在信号超轨（>3.8V/<-0.5V）时导通；0.1× 档大信号时，关断的 X0 引脚经 R8 把节点 A 钳住（5Vpk 误差 -12%，12.7Vpk 误差 -22%，含二极管模型仿真确认）。继电器是机械触点，无二极管、无电容，物理隔离。
- **故障安全**：GPIO 浮空/程序跑飞/断电 → NC → 0.1×（衰减档），大信号不削顶。
- **D1/D2**：仍在 ADC 节点做误操作保护（1× 档误入大信号时钳位）。
- **直流失配**：D1/D2 漏电流失配约 150mV，由固件开机零点校准吸收（100 点平均存 NVS）。

## 5. 音频/输出链路（单 I2S）

```
I2S0主机：BCLK=GP6，LRCK=GP4，DOUT=GP5
  ├─ L声道 = ADC音频 → MAX98357A DIN（SD=5V>1.4V，只取左声道）
  └─ R声道 = 发生器波形 → PCM5102A DIN → ROUT(U2.13)
                                    ↓
                              C3(10uF) → 1k → C1(无极性) → DAC_Out1
                              （软件调幅，不走4053；C3 从 U2.15 LROUT 改到 U2.13 ROUT）
```

- **MAX98357A**：Vin/SD→5V（常使能，不占 GPIO），GAIN→GND（12dB 档）；只播左声道=ADC 音频；ADC 空闲时固件 L 声道填零静音。
- **发生器**：R 声道数字缩放调幅；采样率 ≤96kHz（MAX98357A 上限），发生器上限约 40kHz。
- **BIST 闭环**：R 声道发生 → ROUT → 输出端子 →（探针碰一下）→ ADC → L 声道 → 喇叭。注意配档（1× 满量程 ±1.26V，发生器别打满或切 0.1× 输入）。
- **删除的元件**：4053 整颗、R5/R6/R7/R9/R10、I2S1 相关。GP2/GP11 释放。

## 6. 显示/交互/电源

- **显示**：ST7789 2.4"，VCC/RES/BLK→3V3，CS→GND，K0 悬空（可接 GP11）；EC11：A→GP12、B→GP13、PUSH→GP7。
- **电源**：单节 18650（直接焊接）+ Type-C 5V 2A 升压充放电一体模块（型号引脚待实物核实）。
- **去耦**：Vbias PSRR@1kHz=-76dB；继电器线圈电源加 100nF 就近去耦。

## 7. 固件需求

| 模块 | 要求 |
|---|---|
| Core 0 | ADC DMA 采集（GP1）+ I2S0 双声道（L=ADC音频→喇叭，R=发生器→探针） |
| Core 1 | ST7789 波形 UI + EC11 菜单交互 |
| ADC | DMA 模式；开机零点校准（100 点平均存 NVS）；S3 ADC 非线性需逐档校准 |
| 量程控制 | GP3 驱动继电器；自动量程（默认 0.1×，<10% 切 1×，削顶切回，加回差） |
| I2S0 | 主机，BCLK=GP6、LRCK=GP4、DOUT=GP5；L 声道静音=填零 |
| BIST | 开机自检：R 声道 1kHz → 提示碰探针 → 喇叭响 = 全链路通过 |

## 9. 已知风险与待确认项

1. **PCM5102A 封装硬错**：`KiCad/Elements/footprints/PCM5102A_L_Module.kicad_mod` 的 9 针排做在 VIN 端，实物照片显示应在 SCK 端。PCB 前必须重画封装。
2. MAX98357A 符号 6/7 脚（LRC/BCLK）与仓库照片一致；但**兼容板**顺序可能不同，以用户手上实物为准。
3. PCM5102A 的 H1-H4 焊桥必须全断开（FLT/DEMP/XSMT/FMT 已从排针接 GND/A3V3），实物检查。
4. 各模块 1 脚方向对实物核对；PCM5102A 的 A3V3 不可倒灌。
5. 继电器选型：确认触点耐压 >15V、线圈电流（电池续航评估）。
6. Deep sleep 时若输入端恰有 20V 过载，钳位电流（约 3.5mA）灌入 3V3、无负载吸收（概率极低）。
